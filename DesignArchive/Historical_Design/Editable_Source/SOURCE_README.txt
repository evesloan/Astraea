Astraea master design source
Version 0.3 — 1 October 2026

Astraea_Master_Game_Design.md is the editable text master. The assets folder contains the reference plates and the current registry overview used by the document. Keep those relative paths together when moving the source.

The supplied blueprint, film and game images are reference material. They are not production game assets and this package does not grant rights to redistribute them as game content. The document explains the specific design role of each reference and separates it from original Astraea production work.

The Word document is delivered separately. Accepted edits should be reconciled between the review copy and this text master before publishing a new version. Preserve the status labels so proposals do not silently become confirmed decisions or implemented features.

Governing_Architecture_Brief.txt preserves the complete user-authored architectural refinement brief that chapter 32 summarizes.

Current_Phase_Direction.txt preserves the complete user-authored phase priority. Version 0.3 keeps detailed questline, gameplay and balancing proposals for later decisions while prioritizing the full ship and autonomous staff and guest life.

Species_Canon_User.txt preserves the exact six-species replacement roster. Chapter 8 and dependent sections supersede the former roster. Old runtime indices and original reference images remain legacy evidence, not additional canonical species.

The project_docs folder snapshots the corresponding canonical ship, simulation, daily-life, auditorium, species and architectural-coverage documents updated for this roster. Game code and runtime migration remain separate work.
