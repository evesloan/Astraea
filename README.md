# Astraea production backup

Private project repository for the Astraea Godot resort-liner game and editable Blender catalogue.

- **Game/**: current Godot project. Open Game/project.godot with pinned Godot4.6.3; Compatibility renderer.
- **BlenderCatalogue/**: editable Blender4.3.2 sources, exports, materials, builders and validation records.
- **DesignArchive/**: retained blueprints, reference images, historical master documents and planning records. Historical implementation claims are not current rebuild evidence.
- The authoritative v0.3 master and current decision mapping are in Game/docs/master_source.

The ship is unfinished. All26 Godot check groups passed at the initial backup checkpoint; final visual quality and target-device performance remain unapproved. Catalogue has123 registered editable designs; main-scene presence is not room completion.
