# Astraea independent catalogue continuation

New asset production began on 2 October 2026 while recovery of the original ship workspace was pending. This catalogue contains original new work. It is not a recovered copy of the game, and it does not replace the missing project.

Batch 01 is a compact coordinated day-use family: upholstered window bench, reading chair, day table, and four compatible deep reveal/junction pieces. It translates the supplied residential and premium references into editable low-poly furniture and construction components. Every authored asset is counted once, separately from exports and any LODs. This is one standard day-use construction family, not sufficient variety for every district or luxury tier. The furniture does not claim aquatic use, cocoon provision or universal species fit.

Batch 02 adds seven collection/study designs: three joined structural shelf/canopy pieces, two contrasting study edges and two book/folio details. Two additional stock arrangements reuse the same authored books and are recorded as assembly variants. Batch 03 adds seven staff-only wall, overhead-service and work-cabinet designs. Batch 04 adds six botanical and planted-seat designs. Batch 05 adds six aquatic-leisure designs. Batch 06 adds six engineering utility designs with common mating interfaces and separately named controls/service parts. The catalogue now contains 39 unique authored component designs, with zero adopted game instances. The first botanical family is deliberately small: an open-crown specimen, two low planting forms and joined seating edges. It does not complete the lush garden massing or plant diversity of the references.

## Current verification boundary

Blender 4.3.2 is available on this workspace. Editable source, evaluated GLB export, texture/pivot/dimension checks and Blender component renders are the scope of this batch. The live Godot project is unavailable, so actual room adoption, controls, save continuity, character contact, loaded-cart passage, streaming, in-engine lighting and target-PC performance are pending.

The reference images guide shape, material and use. No courtyard, hull aperture, room capacity or new deck is being created here. Inspection arrangements are asset QA, not playable or proposed replacement ship scenes.

## Backup policy

Local Git records versions but is not a backup. A completed batch must be frozen, hashed, archived and verified in the user's durable Library before a new batch begins. The delivery includes editable `.blend` files, the script-assisted authoring sources, ordinary image textures, GLB exports, manifests, checks and labelled component renders. A portable Git bundle is included when a verified batch is published. Later history may be incremental from a named backed-up commit; complete editable sources never require that optional history step. User-delivery ZIPs stay below 8 MB. Each ordinary source family ZIP includes its editable assets and shared material/generator dependencies. Multiple family packages can be extracted together, with byte-identical shared files. Bulkier review media and optional history are separate. The full unsplit snapshot remains a separate durable checkpoint.

Restoration of the original ship remains a separate process. Any returned original workspace must be verified and fully backed up before game development resumes.
