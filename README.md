# Astraea independent catalogue continuation

New asset production began on 2 October 2026 while recovery of the original ship workspace was pending. This catalogue contains original new work. It is not a recovered copy of the game, and it does not replace the missing project.

Batch 01 is a compact coordinated day-use family: upholstered window bench, reading chair, day table, and four compatible deep reveal/junction pieces. It translates the supplied residential and premium references into editable low-poly furniture and construction components. Every authored asset is counted once, separately from exports and any LODs.

## Current verification boundary

Blender 4.3.2 is available on this workspace. Editable source, evaluated GLB export, texture/pivot/dimension checks and Blender component renders are the scope of this batch. The live Godot project is unavailable, so actual room adoption, controls, save continuity, character contact, loaded-cart passage, streaming, in-engine lighting and target-PC performance are pending.

The reference images guide shape, material and use. No courtyard, hull aperture, room capacity or new deck is being created here. Inspection arrangements are asset QA, not playable or proposed replacement ship scenes.

## Contents

- `assets/furniture`: three new furniture assets and their editable source/export evidence
- `assets/view_reveal`: four joinable reveal/transition assets and their source/export evidence
- `materials`: original shared colour tiles and material metadata
- `standards`: source, scale, material, export and review contracts
- `qa`: independent review and batch-level checks
- `references`: the three user-provided reference images with retained Library metadata
- `tools`: authoring/support scripts

## Backup policy

Local Git records versions but is not a backup. A completed batch must be frozen, hashed, archived and verified in the user's durable Library before a new batch begins. The delivery includes editable `.blend` files, the script-assisted authoring sources, ordinary image textures, GLB exports, manifests, checks and labelled component renders. A portable Git bundle is included when a verified batch is published.

Restoration of the original ship remains a separate process. Any returned original workspace must be verified and fully backed up before game development resumes.
