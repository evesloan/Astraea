# Bounded verification contract

Completed: original retained actual-manager fixture before/after (prewarm off), plus 346-check prewarm fixture. Python helpers compile. No original assertions weakened.

The prewarm fixture uses actual received/private managers, their exact retained two source prototypes, source dispatch, texture interner, grouped contacts and resource loader. Witness booleans isolate policy in headless mode; real renderer witness coverage is explicitly a separate unexecuted gate.

Required cases and evidence:

- Warm hit: complete off-tree visual/body held in single lease, same node transferred exactly once by prepare_position, visible loader and enqueue promotion; geometry/material/contact/local-pose signatures match synchronous baseline.
- Cold miss: visible loader returns with complete resident synchronously; original source and collisions unchanged.
- Unknown/oversize: cheap manifest filter rejects before scene request; unknown closer neighbor cannot displace known eligible candidate.
- Cancellation/reversal: reverse real manager neighborhood interest during threaded wait, configure and ready; queue drains owned request, frees orphan, clears key, never commits abandoned scene.
- Safety takeover: partial orphan cancelled, original synchronous resident ready immediately, orphan drained, exact final signatures; temporary overlap explicitly counted.
- Generation: changed entry generation invalidates ready lease and falls back; identity ownership and existing-resident guards are checked at commit.
- Resident preservation: another room prewarms without evicting visible complete architecture; persistent shell/rest/room IDs unchanged.
- Lifetime: three repeated cycles return node/Resource/contact counts; weak prepared visual references expire. This is not a native RID/GPU or whole-route memory test.
- Exclusions: retained Group2 and private single-pass opt-out remain unsupported. D04/special Night Garden script paths remain unchanged/excluded by the existing supported predicate; not executed in this two-prototype fixture.
- Timing: separately retain admission verification, main-thread preparation/native slices, full scheduler warm consume and synchronous cold fallback. Never call these frame rate.

Unexecuted visual gate: actual notifiers and baseline/warm/cold cameras, first-visible image, final image, signatures and floor ray; zero channel differences required. Display launch is blocked by executor/socket setup, not a passed or failed candidate image comparison. Do not reinterpret the retained one-pixel private failure as a tolerance pass.

Stop condition: this unpublished/default-off experimental package is complete for review once source/tests/receipts and exact limitations are retained. No additional rendering attempts, full build/import/export, source expansion or enablement without a separately authorized next gate.
