# Retained failed attempts

The initial housing assembly applied a world pose to copied descendants after parent assignment, doubling transforms. Its failed native bytes are retained under FAILED_DOUBLE_WORLD_POSE; the final assembly applies a world pose only to roots and preserves descendant local matrices and original mesh/UV/material data. The first real approach collided with the existing D04 SC_StreetBearing column; source notches preserve it and the worker line uses X87. The original rest datum was nominal and did not equal the shaped blanket top; actual native upward cloth triangles now supply the measured surface heights. No mattress or original template was altered. An independent reader initially filtered long object suffixes truncated by Blender; it now uses intact native material identifiers, with unchanged geometry. Initial dark/occluded source views are retained under FAILED_FIRST_SOURCE_CAMERAS. A second preview still used quaternion-mode imported hinges; those closed views are retained under FAILED_PREVIEW_QUATERNION_HINGES. Final preview switches hinge display rotation mode without changing any production geometry or Godot controller. Floor-normal failed bytes are retained under FAILED_MIXED_PRISM_NORMALS; later intermediate native versions were not all saved. Final original-controller tests and native geometry checks supersede, rather than erase, all failed receipts.
