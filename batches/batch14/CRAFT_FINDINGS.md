# Aquatic-use component findings

- Preserve useful motion hierarchy at export. A removable service plate needs its own native root, and its physical surface marker must follow that root. Consolidating the whole plate into the static body loses an already-authored interface even when the zero pose looks correct.
- Start sweep checks at the actual seated pose. A small departure offset must not conceal shallow sill interference or an undeclared unlatching step. Boundary contact and real overlap need different treatment.
- A clear centre ray is not a clear use volume. The rinse gussets occupied the first declared front air box; its actual useful limit is now explicit rather than presented as whole-body shower clearance.
- Supported finish and signage matter at the same time as silhouette. Lettering should have a real supported finish or a declared decal treatment, and exposed cross-material planes should terminate with actual joinery rather than rely on depth bias.
- Continuous throat and receiver checks prove bounded geometry. They do not create cloth behavior, disposal, hygiene or laundry operations. The returned container's source wheels explain its shown support without implying simulated traction or loads.
- Static visual inputs and collision metadata can be versioned separately. Preserve exact source/GLB/camera evidence when a collision-only profile improves, then prove the current generator reproduces the same exports. No new render is needed for an unchanged visible mesh.
- A minimal source-input list includes every file the builder actually loads, including unused material roles loaded by a shared helper. A contact sheet it never reads belongs to QA evidence instead. Keep older overinclusive staging reports intact and classify the current dependency clearly.

All four designs pass bounded independent component review. Actual restore and durable backup remain the release gate; source checks do not establish original-host or engine adoption.
