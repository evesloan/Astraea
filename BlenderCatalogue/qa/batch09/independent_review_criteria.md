# Batch09 independent review criteria

The seven actual references have been inspected as pixels. The three guest references support warm residential task lighting, bounded source housings, readable metal/wood/diffuser separation and integrated useful storage. Library references support concentrated task light, shaped study furniture, browsable low stock and fitted terminals; the monumental upper stock in the fourth reference is not assumed reachable.

- Judge each useful shape and its joins against the relevant full reference and the established tactile low-poly language. No comparative-only approval.
- Inspect actual imported-GLB pixels at 640×360 ordinary standing/seated camera height, plus neutral and detail views. Separate fixtures from emitted-light implementation.
- Fixtures need visible enclosing housings, plausible emitters and access proposals. Terminals need readable display and distinct control surfaces/targets.
- Physical contacts, aperture/pose datums and neutral marker metadata have distinct meanings. Resolve source and native hierarchy; convert source (x,y,z) to native (x,z,-y) exactly once.
- Keep real voids clear in proposed collision. Exercise clear paths and blocked controls. Preserve moving descendants and their frames where applicable.
- Bind inspected sources, exports, manifests, textures and render evidence by exact hashes. Confirm the 45 old canonical rows and all existing source/common resources remain unchanged.
- Source-only rebuild must create its missing output directories and use declared dependencies; exporting a self-contained GLB alone does not demonstrate reproducible authoring.

This is bounded catalogue component review. The original Godot project is unavailable. Gameplay, adopted physics, installed-room clearance, species fit, performance and room/ship acceptance remain outside this review.
