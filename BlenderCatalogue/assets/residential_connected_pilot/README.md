For a new room revision: `blender -b -t 2 --python source/build_family.py -- --plan COURT_PILOT_PLAN.json --revision my_new_revision --domestic`. The current kitchenette is a pinned dependency. The standalone kitchenette accepts `--revision NEW_NAME`; the court generator requires `--output-dir NEW_ABSOLUTE_DIRECTORY`.
