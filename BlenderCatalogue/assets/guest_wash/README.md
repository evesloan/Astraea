# Guest washing fixtures
Three original editable fixtures: a wall-hung vanity with a genuinely hollow basin, a sculpted toilet with a preserved lid hinge, and a low-threshold shower with framed solid-thickness glass. Material roles and metric UVs follow the shared catalogue; source, exports and physical markers remain separate.

The D13 integration checks all fixture bounds against the actual bathroom, confirms usable player approach positions, ray-tests the basin bottom and verifies the shower screen blocks rays from both sides. The bathroom door still passes300 fixed-architecture sweep samples after fixture placement.

These are static fitted fixtures. Water, flushing, lid operation, a real mirror reflection, NPC activities and species-specific use are not implemented. No passenger capacity is assigned by adding a fixture.
