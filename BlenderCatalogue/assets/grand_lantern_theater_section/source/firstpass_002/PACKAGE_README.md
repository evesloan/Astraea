# Grand Lantern Theater, composed source revision 002

This is a new editable source derivative. Original c911 source and a3 first-pass source are preserved. The source is not yet installed in the live ship.

The new source contains nine open vaulted foyer courts, transparent framed backdrops, nine substantial layered planted features, supported luminous coffer and stair-stringer fixtures, and reoriented informal furniture. The 2,200 authored audience chairs are unchanged. The source/route/stance checks are recorded alongside the scripts.

The original entry camera has been retained. Its eight-source image shows clearer lit stairs and a readable court composition, but the destinations remain too dim relative to the near floor. That image is diagnostic, not final visual acceptance. Closer normal-walking and seated views and native Godot light-budget checks remain necessary.

The source renderer caps direct illumination to eight physical bank anchors. Its unsaved camera-only emission shader prevents Cycles emissive GI from supplementing that budget; no global fill/ambient or hidden architecture is introduced. This does not establish native engine selection or target-GPU performance.

The declared source target is `source/AST-CUL-005_firstpass_002.blend`. Construction, independent reopen and render scripts are preserved. Historical run receipts contain paths from the originating scratch workspace; input hashes are authoritative. Every build script refuses to overwrite the existing source/report. A further revision requires a new explicit derivative and output directory.

## Live-world staging

Art refinement is not an indefinite gate to placing checked static work in the ship. Installation still requires exact floor ownership/compiler adoption, actual retained-world neighbour reconciliation, source/import mesh identity, and closed collision barriers at unbuilt receiving routes and lift/secondary interfaces. Doors, cabin, admission and loaded traversal must not be described as operational merely because their geometry is visible. The separate staged-install contract will record the exact new files, floor delta, gates and tests.
