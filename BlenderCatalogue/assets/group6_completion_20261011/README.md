# Editable Group 6 aquatic successor

The selected native and source-derived runtime exchange are pinned by the Group6
fit contract and compact manifest. Retained r001..r014 revisions, held tests,
audits and source views are historical evidence. Use only the selected revision
in `Game/docs/group6_completion/INTEGRATION.md` for adoption.

The original aquatic native was saved by Blender5.1.2. The environment's Blender4.3
cannot open it; that failed attempt is retained. `author_completion.py`,
`verify_native.py` and `render_source.py` run with official matching `bpy==5.1.2`
in an isolated workspace Python3.13 venv. They do not modify the retained original.
Godot remains pinned4.6.3. The package vendors neither a virtual environment nor
modified dependency/transfer helpers.

Authoring opens the original by its exact SHA256, creates derived/additive native
meshes, preserves original vertex/face/UV/transform/material-name/modifier
semantics and packed image bytes, and writes a new native revision before creating
an exchange scene. `EXCHANGE_PARTS.json` maps batched runtime meshes to exact native
parts. `COLLISION_POLICY.json` identifies static solids, moving privacy leaves,
controls, decorative finish, water and static rings explicitly.

The fresh native verifier checks all original source hashes and packed images,
138 new furnishing support points, conservative original-solid/furnishing AABB
separation 16 actual roof/canopy mount contacts and a separately regenerated byte-identical runtime export. It does not
accept engineering, whole-mesh per-height hull fit, swimming, hardware or final art.
The view script changes camera/cutaway only in memory and never saves its staging
back to the native. Neutral Workbench views expose geometry and source base colors;
they do not represent game light, textures, guests, fluid physics or final art.

Protected inputs, final receipts, acceptance limits and shared boundary contracts
are in `Game/docs/group6_completion`. Production adoption is deliberately owned by
the shared integrator. This group does not edit root builders, floor/programme
registries or checkpoint refs.

The current saved source is r015. Two visible continuous recovery paths replace
the held sharp/rounded-riser trials, and two thermal courts now have exact curved
bank joins, real basin entry surfaces, handrails, canopies/screens and support
hardware. The native author refuses to overwrite an existing retained native;
choose a new unique output revision before a new authoring run. The immutable
saved-source generator snapshot is `AUTHOR_R013_SAVED_SOURCE.py.txt`.

The r015 bay includes 345 authored meshes and 12 native reference meshes from the
exact registered staff threshold. The unchanged runtime gate asset is loaded
separately; reference meshes never enter the main export. Mechanical handwheels
are individual exports with safe names that avoid reserved importer suffixes.
The source retains r014 and all failed import/placement evidence. Mechanical
operation does not accept a pump/filter/pressure/flow/temperature network.
