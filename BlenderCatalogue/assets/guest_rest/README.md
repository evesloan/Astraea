# Guest rest family

Two original editable sleeping-furniture components extend the approved DAY furniture language: a single rest bed and a double rest bed. Swept timber headboards, padded fronts, a recessed cleaning-friendly base, fitted mattresses, folded linens, tailored pillows and teal runners use intentional low-poly profiles. New neutral linen is an original deterministic256px weave. No reference pixels or borrowed meshes.

The approved intimate and premium suite references informed materials and layering. This does not assign these components to particular species or luxury tiers, and does not change room counts, berths or the2,000-passenger admission limit. Two sleeping places are a component proposal, not a capacity record.

Both editable sources reopen and export to GLB with matching evaluated bounds, floor contact and metric UVs. Component renders were visually reviewed and exposed a recessed head pad, which was corrected. Sleeping poses, species fit, movable bedding, runtime collision, LODs and actual room integration remain untested. Preview images are Blender component QA, not screenshots of completed guest rooms.

Builder dependency: existing assets/furniture/build_furniture.py and standards/materials.py. Source keeps semantic geometry and modifiers; GLB evaluates and batches the static visual. All sources, helper dependencies and textures are retained by the catalogue backup.
