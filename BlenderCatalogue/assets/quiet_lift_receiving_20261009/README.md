# Quiet Grove passenger lift successor

Editable retained-house derivative for the five commons, D13–D17. Runtime admission and tests are recorded separately; this source does not establish final art or complete Group 1.

The southern commons pocket is centred at X91, gate Z−362.1, yaw−90°. The 23 m² recess on each level is subtracted only from the five named commons source slabs, retaining their stair openings. All other source parts and all 250 landscape placements remain in place. Existing 83 guest interiors and the 143-member Library composite are unchanged.

A glazed shaft, fitted portal infills, cap and pit are added. Two short crossbearers overlap the existing X95.8 longitudinal at its top Y83.76. This is geometric receiving contact, not structural capacity certification. The original principal cover remains intact. The existing five-stop cabin and common controller supply gates, physical motion and focus/E buttons.

The original native Blender source and runtime r002 remain retained. The derivative carries the already-installed upward floor-top winding correction into editable source. Regenerate the geometry plan with source/prepare_lift_geometry.py (Shapely 2.1); then run source/build_lift_geometry.py with Blender 4.3.2. Its optional ASTRAEA_RETAINED_QUIET_NATIVE value may point at a decompressed copy of the retained native input. Otherwise it decompresses the retained input to a temporary directory itself. Never replace original sources.

Source-fit review checked the actual retained assets, 83 home allocations, five floor polygons, nearby lower programme and the existing longitudinal. The main eight-metre arrival strip stays intact.
