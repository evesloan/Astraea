# Batch08 — bounded catalogue integration readiness

This pass addresses known source/component adoption issues in the existing 45-design catalogue before adding another family. It does not rebuild the missing game or certify native engine performance. The verified Batch07 snapshot is the immutable comparison baseline, commit 66dcaf10f105958c5cadb421d5aca15b054b98ed, durably delivered before this work.

## Scope

1. Replace the fragmented hospitality curved-return collision proposal with a much smaller meaningful compound representation. Preserve real shelf/service openings, floor/support and seam regions, separate moving parts and correct source/GLB frames. Start with AST-HSP-002's 263 pieces and report exact changes to the 399-piece hospitality baseline; inspect the straight counter's 26 pieces for safe related reduction. Other components remain unchanged unless a concrete source-backed fit issue is identified. Do not use one enclosing solid hull or count decorative ribs as mandatory separate colliders.
2. Produce an economical derived shared-flange representation for repeated/distant utility installations. Retain existing detailed sources and exports byte-for-byte where possible. Preserve the shared dimensions, bore and actual port/hole-phase/pivot records, clear material identity and useful silhouette. Compare actual exported high/detail and economical geometry at near and repeated-use viewing distances. Lower-detail parts/LODs are derived outputs, not additional artistic designs. This is not a whole-ship LOD or native performance certification.
3. Audit all 45 current asset interfaces for explicit units, datum, source/exchange frames, transforms, contact versus pose meanings, motion hierarchy and required source dependencies. Verify actual exported node/geometry records where provided. Identify real ambiguities or missing required fields; do not invent contact points, operating behavior, missing source or universal species fit. Fix concrete omissions in versioned current data with exact preservation evidence.

## Ownership and preservation

The collision worker owns only the counter-family collision proposal and its generator/documentation/manifest dependency records. Existing .blend and visual GLB bytes must remain unchanged for this geometry-independent correction. Any geometry conflict must be reported before wider edits.

The flange worker owns new derived files under assets/utility_pipework/derived_lod plus a new helper if required. Do not rewrite the existing six utility master sources or GLBs, or change their original helpers by default. The lead coordinates catalogue index/README/backup records and concrete cross-family interface corrections. The interface auditor is read-only except qa/batch08/interface_* reports and proposed data; the independent reviewer owns qa/batch08/independent_*.

## Gates

Measure reductions and bounds from actual exported/compound geometry, not declared budgets. Retain positive blocked controls and negative open-space controls, and check approximation errors around real source surfaces. Near-source/old evidence stays intact and versioned. Add finite motion tests only where a real moving interface exists; do not call offline rays or samples an engine-physics pass.

Use current actual-GLB imagery, coordinate contract and relevant original reference pixels. Economical geometry must be judged in matched actual imported-GLB views, with material/UV/normal/source editability checks. Serialize heavy renders through the lead. Source/fixture corrections use focused tests; do not repeat unaffected earlier rendering.

Independent review is followed by a clean source freeze, full archive, complete compact family source packages, actual offline restoration and durable Library delivery. The unique artistic-design count stays 45. No new asset family starts during this readiness pass.
