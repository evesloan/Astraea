## Menus and preferences

The menu supports Enter the ship, Resume, Settings and Quit. F10 opens the pause menu after readiness; the existing M directory owns its own pause and is not interrupted. Esc retains pointer-release behavior. Settings reuse the original presentation resolution/effects controls, and add fullscreen, master volume and 30/60/120 frame caps. F3/F4/F11 use the same persisted preferences. No architecture is hidden or removed for a performance preset.

Preferences are stored in Godot's `user://astraea_preferences_v1.cfg`, outside source. This is not a saved game or AFK/transport-state persistence. Invalid values are bounded; read/write failures are shown. Preference checks and a small simulated readiness interface are not evidence that the full ship launches.
