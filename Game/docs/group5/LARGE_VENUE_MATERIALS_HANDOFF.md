# Native material factor restoration

Eight native image/Mix color multipliers were missing from the five otherwise byte-matching current GLBs. Five orange identity/material families and three green planting families therefore appeared as their untinted original image texture. The native graph is an image feeding Color1 of a legacy MULTIPLY Mix node, with constant factor1 and a constant Color2, feeding Principled Base Color. No complex or unverified shader graph is approximated.

`LARGE_VENUE_MATERIAL_FACTORS.json` records the exact source linear factors, original export factor preimages and immutable model/native hashes. `qa/LARGE_VENUE_NATIVE_MATERIAL_GRAPHS.json` retains read-only graph inspection of all current materials. Source natives, current exports, images, room IDs, capacities, geometry, floors, routes and controls remain immutable.

The runtime builder creates shallow copies of only the eight selected material resources and applies them to976 surfaces across Copper Kettle, Paper Moon, Post & Parcels, Starlight Bakery and Companion Games. Original texture objects, roughness, normal, emission, opacity and other PBR fields remain unchanged. Unselected materials retain their exact original resources. Copies belong to the original cached room nodes, and repeated builds reuse them.

Godot's glTF importer converts linear `baseColorFactor` values to the material's sRGB color property. The builder performs source multiplication in linear space and then uses the same conversion. The governing primary implementation is [Godot4.6 GLTFDocument](https://github.com/godotengine/godot/blob/4.6-stable/modules/gltf/gltf_document.cpp). The independent check creates temporary GLBs with only native factor JSON fields changed, preserving complete original BIN and image bytes, and compares the material copies with actual importer results. These temporary witnesses are tests, not production replacements or source recovery claims.

Apply `LARGE_VENUE_MATERIALS_AFTER_LIGHTING.patch` after the Group5 construction and five-venue lighting calls. It adds one call before shared occlusion/residency setup.
