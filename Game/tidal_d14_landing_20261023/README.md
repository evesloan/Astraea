## Reproduce without a full import

With the project's existing Godot 4.6.3 environment active, run:

```
godot --headless --path Game --script res://tidal_d14_landing_20261023/check.gd
godot --headless --path Game --script res://tidal_d14_landing_20261023/check_entrypoints.gd
```

Native source and construction/render scripts are in `BlenderCatalogue/assets/tidal_d14_landing_20261023`. Runtime bake uses fresh GLTF bytes and embeds resources; it refuses to overwrite the named `.scn`. Native construction likewise refuses to overwrite its named revision. Use a named successor for future edits. No whole-ship import, export or launch is required for these focused checks.
