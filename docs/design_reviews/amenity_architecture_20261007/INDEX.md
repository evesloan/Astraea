## Portability and integrity

- `originals/` contains exactly the requested 13 MD/JSON reports and two JPG captures. They have not been edited or silently relinked.
- `SOURCE_MAP.json` maps every copied original plus all 49 reviewed source image paths, pinned inputs and key references to portable repository-relative paths or exact retained Library archive IDs/members. Large archives and full image sets are intentionally external dependencies.
- Existing Game and BlenderCatalogue inputs remain at their pinned project paths. The Logan's Run and craft DesignArchive originals exist in the retained checkpoint only; SOURCE_MAP.json identifies their exact checkpoint paths rather than pretending they are current working files.
- `MANIFEST.json` lists the new repository destination, byte count and SHA-256 of each payload file. `SHA256SUMS` also protects MANIFEST.json; the checksum list excludes itself. Check with `sha256sum -c SHA256SUMS` from this folder.
- `.gdignore` prevents this evidence directory from becoming an engine import surface.
- `RETENTION_CHECK.json` records the no-overwrite preflight against the recovered Game. Recheck immediately before copying. If any destination exists, stop and reconcile; do not merge over or replace surviving content. Copy only this folder, never its staging wrapper or ZIP.

The bundle excludes raw connector responses, signed URLs, helpers, large ZIPs, base64, authentication paths and secrets. It is project evidence, not a new source package or independent backup by itself.
