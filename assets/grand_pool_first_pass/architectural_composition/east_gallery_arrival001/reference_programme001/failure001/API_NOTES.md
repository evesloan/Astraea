# Retained programme source helper

Prepared only. No Blender or Godot process, render, save, export, or Game/Catalogue write was performed by this package.

## Combined builder API

1. Import `source_blockin001/build_core.py` and call `build_core()` without calling its `main()`. The result is `(plan, material_provenance)` and an unsaved Blender scene.
2. Add this directory to `sys.path`, import `append_retained_programme`, and call `append_retained_programme.append_retained_programme(core_plan_path)` with the absolute `source_blockin001/CORE_PLAN.json` path.
3. The callable checks immutable inputs and the matching pure gate, appends seven semantic programme roots, and returns JSON-serializable provenance, exact root/object lists, retained source fingerprints, and intended-frame verification. It does not save, export, render, reset the scene, or launch anything.
4. Call `append_retained_programme.snapshot_retained_programme()` after linking/updating. Persist the returned raw editable geometry, UV/material, transforms/properties, and evaluated world triangles alongside the combined builder's own evidence.
5. Run a fresh independent source reopen and call the snapshot API again. Compare the entire returned evidence exactly before semantic fit checks. The parent's core roundtrip helper can compare this JSON. `check_programme.run(evaluated_snapshot, actual_core_plan=BUILD_EVALUATED_CORE)` also accepts the programme dictionary or its JSON path, plus the evaluated core-plan dictionary or path to repeat the real placement/soil/ray/contact screen on separately editable source meshes. It does not expect batched GLB mesh counts. When `actual_core_plan` is supplied, exact part identity/family/support and vertices must match the pinned float32 core; its actual `evaluated_triangles` are consumed instead of re-triangulating polygons. The actual-source soil gate takes root-base vertices from evaluated retained root parts and contact marker positions from reopened EMPTY world matrices. The default pure planned review remains unchanged.

The combined builder owns the single save, retained copy, and independent reopen. Later renders should include `SOURCE_ONLY_RetainedProgramme`, even though every reference has `architecture_export_excluded=true`. A later architectural export must exclude all of these references. The one selected display may later become an explicitly extracted AST-LIB-010 derivative; never duplicate the old four-screen runtime assembly.

## Pure checks and scope

`python check_programme.py` checks the pinned independently reopened full-crown source triangles and actual retained basal/display/sign GLB triangles. It verifies soil projection and all root contacts, nine original mounting contacts, the arrow/backing interface, actual new intersections, protected/approach/cart routes and apron, all15 image-centre/corner rays, market and preserved rays, and sign-centre rays. Tolerance is the retained5e−5m contact tolerance. Open leaves, botanical surface batches, and the zero-thickness artwork cannot serve as closed-solid interiors; their actual surfaces are still checked against closed receivers.

The first diagnostic caught two real fore basal/container intersections and five unique escaped projected leaf vertices (18 duplicated GLB corners). The core author changed only the fore soil/container corner profile, keeping its cardinal bounds/heights, leaving all retained plant geometry and transforms intact. Initial and surface-corrected diagnostics are preserved. No problem was concealed by rescaling, dropping a plant, or relaxing tolerances.

`python test_programme.py` runs six pure frame/handedness, source-instance, mount/arrow, forbidden-operation, and open-surface regression tests. `INPUT_PINS.json` pins inputs; `PACKAGE_SHA256.json` pins final helper/review/test deliverables. Source reopen, composed pictures, native lighting selection, and live capsule/cart/game views remain separate unperformed gates.
