# Guest privacy door
An original opaque single-leaf door with separate editable hinge, fixed frame and lever contacts. The hinge is offset85mm beyond the frame centre, with recessed side stops, so the leaf can rotate clear of its jamb. Export batching preserves the hinge hierarchy.

In the actual D13 bathroom it extends the existing service-door behaviour through a small geometry adapter. Shared RMB/E interaction, motion and obstruction handling remain in the original controller.300 motion samples pass against fixed room/frame collision, along with exact camera targeting, unfocused-E rejection and occupied-swing inhibition. No save state, lock, loaded-cart or species fit is claimed.
