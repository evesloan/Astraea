Graphs retain node types, values, input defaults, links, shader RNA parameters, image sampling parameters, recursive groups, ramps/mappings and packed image bytes. Only material/image name suffixes are normalized; UI layout is not shader state. All used images must be packed.

- Actual source plant/root positions and transformed prototype vertices against frozen soil receivers, nominal embed/depth, and actual new-to-preserved collar separation. Three optional fuller root rings and all emitted vertices are checked against the rear receiver.
- Actual printed-stack source triangle witnesses: corners, edges and interior on a 9-by-9 grid, plus exact stack interface planes.

## Report semantics

Only complete success creates `../printed_materials001/authored_preview001/REOPEN_REPORT.json` with status `PASS_SOURCE_ONLY`. Existing reports are never overwritten. Failures create uniquely named evidence here and raise the error.

No geometric/load/visual/runtime acceptance beyond the actual checks is implied. In particular, old soil/collars are frozen contract receivers tied to the unchanged base hash; printed support uses grid witnesses rather than a continuous support proof; botanical joint penetration, route simulations, physical loads, art legibility, and runtime/six-species acceptance remain outside this source-fidelity test.

`PREPARATION_AUDIT.json` records the pure AST/import/inspection audit and script hash.
